# Suprize — suprize.net

Корпоративный сайт компании по поставке премиальной сантехники в Кыргызстане.

- Домен: **suprize.net**
- Языки: кыргызский (по умолчанию), русский, английский

## Стек

- React
- Vite
- TypeScript
- React Router
- TailwindCSS
- Lucide React
- Framer Motion

## Запуск

```bash
npm install
npm run dev
```

## Сборка

```bash
npm run build
```

## Деплой на Cloudflare Pages

- **Build command:** `npm run build`
- **Build output directory:** `dist`
- **Node version:** 18 или выше

Файл `public/_redirects` настроен для корректной работы клиентского роутинга.
